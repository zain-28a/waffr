# Device test plan (November 2026 overhaul)

What the cloud session could not check because it had no Android SDK,
phone, emulator or Mac. Everything else was covered by `flutter analyze`,
the test suite and a web build (see PERFORMANCE_AUDIT.md).

Run on an Android phone (Android 12 or newer, plus one Android 8-11 device
if possible), with a profile build for the performance part:

```sh
flutter build apk --profile
```

## Home-screen widgets (Android)

The Kotlin and layout XML were written without compiling them. Build the
APK first; any compile error points at
`android/app/src/main/kotlin/com/waffr/app/widgets/WaffrWidgets.kt` or
`res/layout/widget_*.xml` (generated by `tool/build_widget_layouts.py`).

1. Add each widget: الرصيد، هذا الشهر، إضافة سريعة، هدف التوفير،
   الالتزام القادم، سلسلة الأيام.
2. Resize each one through small (2x2), medium (4x2) and large (4x3 or
   more) where offered. Check the layout changes with the size, nothing is
   cut off, and Arabic reads right to left.
3. A quick-add widget placed one row high before the update shows two
   buttons side by side.
4. Taps: balance opens home, the expense and income buttons open their
   sheets, this month opens Reports, recent opens the expense history,
   goal opens Savings (or create goal), bill opens obligations, streak opens
   the profile.
5. Add an expense in the app: every widget updates within a second or two.
6. Settings → المظهر → إخفاء المبالغ في الأدوات: amounts turn into dots,
   percentages stay.
7. Dark mode: switch the phone theme; colors follow (category dots use the
   dark palette).
8. Change the phone date to the next month without opening the app: the
   month widget asks to open the app; "اليوم" / "أمس" in recent rows and
   the bill's "غداً" / "بعد N أيام" move with the date after the next
   six-hour refresh (or after removing and re-adding the widget).
9. Android 8-11: resizing redraws the matching layout.

## Notifications (Android)

1. Quiet hours: set the phone clock to 22:30 and trigger an alert (spend
   past half the period's balance): it appears in the bell list but no
   banner shows.
2. Daily limit: trigger two non-urgent alerts on the same day (a goal
   reaching 50%, a large expense): one banner, both in the list. A balance
   warning still shows a banner.
3. Logging nudge: log nothing for three days (move the clock); one banner
   at 20:00 on the third day, not repeated.
4. Comeback reminders and the Friday digest never land on the same day.
5. Turning off "تنبيهات ذكية" stops the forecast, pace, goal-deadline,
   period-summary alerts and the reminders.

## Tutorial

1. Fresh install: after sign-in and the theme choice, the tutorial starts
   on the balance card.
2. Walk all 8 topics. In the income, expense and goal sheets save once:
   the balance, expenses and goals are unchanged afterwards.
3. Close a demo sheet without saving: the step goes back to "open it".
4. Kill the app mid-way and reopen: it resumes at the start of that topic.
5. Skip: the question appears; "الخروج من الدليل" ends it for good.
6. Help → ابدأ الدليل starts it again from the balance.
7. Existing install updated from the previous version: the tutorial shows
   once.
8. With goals already created, the "create goal" step shows "التالي".
9. Large text (accessibility font scale 1.3): cards stay on screen and
   readable.

## Performance (profile build, DevTools)

1. Home tab with a large ledger (import or generate 3,000+ expenses):
   adding an expense should not drop frames when the insight bar updates.
2. Open the smart analysis (all three tabs): first frame of each under one
   second on a mid-range phone.
3. Scroll Settings, Help, Reports and Savings; check the raster and UI
   thread timelines for frames over 16 ms.
4. With the tutorial running, scroll to the spending card: the window
   follows smoothly.

## iOS

The iOS widgets and iOS device notifications were not changed in this
overhaul (Android only, by decision). If iOS ships, check that the app
still builds and that its widgets show the older design.
